# collegian.io

A daily, Kahoot-style speed trivia game: an athlete appears, you type the
college they went to. The athletes get more niche as the day's run goes on,
and your points carry you from **Orientation** to **Valedictorian**.

Project status: discovery / planning. See [docs/PLAN.md](docs/PLAN.md).

Until the app exists, [placeholder/](placeholder/) holds a static "coming
soon" page for the domain; the root `vercel.json` deploys it on Vercel.
